# Velocis Mini Windows packaging

This folder contains the Windows packaging script for the standalone Swing Compiler Studio.

## What the installer bundles

- Velocis Studio Java application
- `velocis.exe` compiler
- A private Java runtime generated by `jpackage`
- Start Menu and Desktop shortcuts

The target laptop does **not** need Java, Flex, Bison, GCC, or MinGW installed. Flex/Bison/GCC are only needed to rebuild the native compiler from source.

## Build the installer

Run this on a Windows machine with:

- A full JDK installed (`javac`, `jar`, and `jpackage` available on PATH)
- WiX Toolset installed and available on PATH (required by `jpackage` for the Windows EXE installer)

From the project root, run PowerShell:

```powershell
.\packaging\package-windows.ps1
```

The installer will be written to `dist`.

## Project layout expected

```text
Velocis/
  velocis.exe
  velocis-studio/
    VelocisStudio.java
    LexicalAnalysisWindow.java
    Velocis-icon.png
  packaging/
    package-windows.ps1
```

## Important testing

Build and test the installer on Windows. Install it on a second Windows laptop (or a clean Windows VM) that does not have Java or compiler toolchains installed. Verify Build & Run, runtime input, AST, and Lexical Analysis.
